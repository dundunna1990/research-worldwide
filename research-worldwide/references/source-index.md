## How to use

1. Scan ALL ten categories and entries below when choosing relevant original research routes, including broad scholarly discovery, regional and multilingual sources, institutional repositories, specialist directories and relevant discussions. Categories are navigation aids, not subject restrictions.
2. Identify all reasonably relevant entries by name and short purpose; review apparent cross-domain candidates and revise selections as new leads emerge. Skip clearly unrelated routes and preserve status tracking.
3. Read the FULL ORIGINAL ROW for each chosen source from references/source-catalog.md using targeted line/range reading; each row below gives its current 1-based line. Example: sed -n "17p" references/source-catalog.md (use the line number of the actual index entry). The route may require using the website instead of an API.
4. Include the catalog preamble (lines 1–11) at least once when using this index, unless those rules are already known from the skill. If targeted reading is unsupported, read the necessary catalog section rather than inventing route details. Full-file reading is a fallback, not forbidden.
5. Do not confuse checking this index with executing source searches. Do not invent permission, a keyword-search route, language capability or full-text access based on this short index. When catalog version/hash differs, regenerate/reconcile the index before relying on line numbers; fall back to the catalog meanwhile.
